# Release v2026.10.24.1

- Deployed: 2026-10-24 (server and runner)
- Commit: `d0c43ed3c54016df8f5cb520aa6c286890922c16`
- Previous production release: [v2026.10.22.11](v2026.10.22.11.md) (`b7a31e42`, server and runner)
- Range: `v2026.10.22.11..v2026.10.24.1`, 49 commits
- Release class: ordinary. An independent review of the whole range answered
  no to both questions of
  [High-risk change release](../operations/high-risk-change-release.md)
  (one FS candidate and five TL candidates, each changed only in how text is
  cut or how a result is clipped). No SDK, CLI or native pin changed, and the
  server change is test-only.

## Highlights

- **First schema-2 release tag.** `v2026.10.24.1` is the first tag created by
  the release operator with `scripts/release-tag.mjs plan` (cutover C4 of the
  [issue 709 plan](../plans/issue-709-release-reduction.md)). Landings on
  develop no longer create version tags (C3). From this release on, a `v*` tag
  means "released"; earlier `v*` tags mean "landed".
- Antigravity peers on a Gemini Flash or Pro model report the correct weekly
  rate limit again
  ([issue #725](https://github.com/sakuraiyuta/kaoiro/issues/725)).

## Changes

### Wrappers

- Antigravity: `/usage` buckets are selected by exact id. A model-specific
  weekly bucket added by the CLI (Gemini 4 Argon) no longer overwrites the
  `gemini-weekly` bucket, which showed the weekly window as blocked at 100%
  ([issue #725](https://github.com/sakuraiyuta/kaoiro/issues/725),
  [issue #734](https://github.com/sakuraiyuta/kaoiro/issues/734)).
- Antigravity: the result text is clipped to the shared 16 KiB cap, so a long
  reply no longer loses its result envelope
  ([issue #631](https://github.com/sakuraiyuta/kaoiro/issues/631)).
- Claude Code: a text attachment with malformed UTF-8 is bounded by
  `TEXT_SDK_BYTE_LIMIT` after decoding, with the truncation notice
  ([issue #634](https://github.com/sakuraiyuta/kaoiro/issues/634)).
- All wrappers and the runner: free text cut to a fixed length (stderr tails,
  Office extraction, resume summaries and diagnostics) no longer splits a
  surrogate pair
  ([issue #630](https://github.com/sakuraiyuta/kaoiro/issues/630)).
- Grok: a replayed history entry is cut at the same character boundary as the
  live path
  ([issue #653](https://github.com/sakuraiyuta/kaoiro/issues/653)).

### Dashboard

- The previous/next agent labels, the agent strip chip title and the history
  dialog titles show the directory name after a rename, like the timeline
  ([issue #670](https://github.com/sakuraiyuta/kaoiro/issues/670)).
