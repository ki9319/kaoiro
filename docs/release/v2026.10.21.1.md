# Release v2026.10.21.1

- Deployed: 2026-10-22 (server and runner)
- Commit: `3eaf5c9973df7b433b3bde619493dca9828a4d9f`
- Previous production release: [v2026.10.20.5](v2026.10.20.5.md) (`a470e90b`, server and runner)
- Range: `v2026.10.20.5..v2026.10.21.1`, 3 commits
- Release class: TL (an engine SDK pin change, affecting the claude-code
  engine only). The server code and the runner start path are unchanged.

## Highlights

- Claude Code peers run on Claude Agent SDK 0.3.306, which bundles Claude
  Code 2.1.306. This clears the 2.1.295 minimum that `onFailure` command
  hooks need ([issue #700](https://github.com/sakuraiyuta/kaoiro/issues/700)).

## Changes

### Wrappers

- Claude Code: the Agent SDK is 0.3.306. The SDK compatibility review and
  the production init-only catalog probe were rerun; the probe still
  projects 13 catalog rows
  ([issue #700](https://github.com/sakuraiyuta/kaoiro/issues/700)).
- Claude Code 2.1.302 and later enable fork subagents by default; peers now
  get them.

### Tests

- The native framing pins for Monitor notifications and background Agent
  hand-backs were measured again through the production CLI and are
  unchanged. The scripted provider loads deferred tools through ToolSearch
  ([issue #700](https://github.com/sakuraiyuta/kaoiro/issues/700)).

## Upgrading

- Update the server and the runner to the same commit.
- The release is TL: follow the canary stage in
  [High-risk change release](../operations/high-risk-change-release.md).
  The canary is the claude-code persona.

## Known issues

- Known advisories in server dependencies and a deprecated XML library are
  tracked in [issue #701](https://github.com/sakuraiyuta/kaoiro/issues/701).
- The SDK bump procedure does not yet make the fold re-measurement and the
  CLI changelog review standing steps
  ([issue #702](https://github.com/sakuraiyuta/kaoiro/issues/702)).
- The server deploy CLI still refuses an update when a
  `docker-compose.override.yaml` is present; move it aside during the
  deployment and restore it afterwards (part 1 of
  [issue #681](https://github.com/sakuraiyuta/kaoiro/issues/681)).
